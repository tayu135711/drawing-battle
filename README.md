# ラクガキ王国

自分で描いたキャラクターが、ぷっくり立体になって戦う3Dブラウザゲーム。
Three.js + 素のJavaScript（フレームワークなし）。セーブデータはブラウザのlocalStorageに保存。

## あそびかた（ローカルで確認する場合）

このフォルダをまるごとダウンロードして、`index.html` をブラウザで開くだけで動きます。
ただし `file://` で直接開くとブラウザによっては読み込みに失敗することがあるので、
簡易サーバーを立てるのがおすすめです。

```bash
# このフォルダの中で実行
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pagesで公開する場合

1. このリポジトリの Settings → Pages を開く
2. "Source" を `Deploy from a branch` にして、ブランチは `main`、フォルダは `/ (root)` を選択
3. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## ファイル構成

- `index.html` — 画面のHTMLとCSS、Three.js本体の読み込み
- `game.js` — ゲームのロジックと描画（このファイルだけで完結）

## 主な機能

- キャラクターの手描き→ステータス自動計算→3Dぷっくりキャラ化
- ステージ制バトル（リアルタイム自動戦闘）
- フィールドたんけんモード（3D空間を歩き回り、敵と接触でバトル）
- ポケモンふうのターン制バトル（たんけんの遭遇戦。技選択・タイプ相性・こうたい・にげる）
- 効果音・BGM（WebAudioでその場合成、音声ファイルなし）
- 全5ステージ、各ボス、宝箱、絵の具（色）の段階解放

## 追加機能（v5.5 相当）

| 機能 | 内容 |
|---|---|
| ✨ 描き足し進化 | Lv.MAX のキャラに1回だけ。今の絵を下絵に描き足して +25%。 |
| 🎨 今日のお題 | 日替わりの描き方の縛り（3色以下・大きく・赤メイン等）。クリアで描いたキャラに +10%。`DQ_LIST` に足せば増える。 |
| 📖 モンスターずかん | 通常5種＋ボス5体。撃破数で★。実時間バトルとターン制の両方で記録。 |
| 🗡 そうびを描く | 1キャラ1つ。一番多い色で効果が変わり、大きく描くほど強い（+5〜25%）。バトル中も表示。 |
| ⇋ 左右たいしょうペン | ONにすると中央線を軸に左右対称に描ける。 |
| ⭐ スタンプ | ほし・ハート・まる・とんがりをワンタップで。サイズと対称に対応。 |
| 🏅 しょうごう | 15種の実績。タップで称号としてホームに表示。 |
| 🤝 こうかん | キャラを共有コード（`RKG1:...`）にして送受信。受信側で数値を上限内に丸め、PNG以外は拒否。 |

セーブデータは `rakugaki-kingdom-v1` のまま（古いセーブもそのまま読める）。
