# ラクガキ王国

自分で描いたキャラクターが、ぷっくり立体になって戦う3Dブラウザゲーム。
Three.js + 素のJavaScript（フレームワークなし）。セーブデータはブラウザのlocalStorageに保存。

## あそびかた（ローカルで確認する場合）

このフォルダをまるごとダウンロードして、`index.html` をブラウザで開くだけで動きます。
ただし `file://` で直接開くとブラウザによっては読み込みに失敗することがあるので、
簡易サーバーを立てるのがおすすめです。

```bash
# このフォルダの中で実行
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pagesで公開する場合

1. このリポジトリの Settings → Pages を開く
2. "Source" を `Deploy from a branch` にして、ブランチは `main`、フォルダは `/ (root)` を選択
3. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## ファイル構成

- `index.html` — 画面のHTMLとCSS、Three.js本体の読み込み
- `game.js` — ゲームのロジックと描画（このファイルだけで完結）

## 主な機能

- キャラクターの手描き→ステータス自動計算→3Dぷっくりキャラ化
- ステージ制バトル（リアルタイム自動戦闘）
- フィールドたんけんモード（3D空間を歩き回り、敵と接触でバトル）
- ポケモンふうのターン制バトル（たんけんの遭遇戦。技選択・タイプ相性・こうたい・にげる）
- 効果音・BGM（WebAudioでその場合成、音声ファイルなし）
- 全5ステージ、各ボス、宝箱、絵の具（色）の段階解放
